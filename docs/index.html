StudyQuest

Esta pasta docs/ existe para impedir que o GitHub Pages falhe com o erro No such file or directory @ dir_chdir - /github/workspace/docs quando o site estiver configurado para publicar a partir de uma branch.

Para publicar a aplicação React completa, abra Settings → Pages no repositório, selecione GitHub Actions em Build and deployment e execute o workflow Deploy StudyQuest to GitHub Pages.

O workflow compila o Vite e publica a pasta dist, que é a versão correta do app StudyQuest para produção.
